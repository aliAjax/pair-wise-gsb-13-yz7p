# 加油站遗失物保管台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

由“加油站班次交接”扩展而来，把原先纸盒 + 口头交班的遗失物管理升级为留痕的保管台。数据默认保存在浏览器 localStorage，方便后续替换为接口与权限。

## 功能闭环

- **登记发现**：记录发现站点、时间、物品特征、暂存位置、发现人与保管天数；同一特征在保管时效内重复登记时，只向原物品追加“补充发现”记录，不新开一件。
- **认领核对**：逐项核对姓名、联系电话、物品细节（细节按与登记特征的文字重合度判断，防止仅凭一句描述冒领）。三项全部通过才进入“待发还”；若已有另一名顾客通过核对，则立即转为**争议冻结**，不得把物品交给后到的人，须站长裁定。
- **换班移交**：交接班时全部在管物品的保管责任人随记录移交给接班人，移交动作、在管件数与交班说明留痕。
- **处置归档**：超过保管期或确认无人认领时才可归档，且必须登记处置人和去向；待发还/争议中的物品不能按无人认领归档。
- **归档更正**：已归档记录允许更正暂存位置、处置人、去向等登记差错，原值、新值、更正人与原因全部保留在记录轨迹中。

## 代码分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `src/lostfound/types.ts` | 遗失物、发现、认领、移交、处置、更正的类型定义 |
| 判断 | `src/lostfound/rules.ts` | 时效、同特征合并、认领核对、争议冻结、移交、归档与更正的纯函数规则 |
| 本机保存 | `src/lostfound/store.ts` | localStorage 读写与演示种子数据 |
| 页面 | `src/App.vue`、`src/components/ModalShell.vue` | 交互与展示，不直接包含业务判断 |
