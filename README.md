# 加油站遗失物保管台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

由班次交接页扩展而来：把纸盒里的顾客遗失物搬进保管台账，交接班不再靠口头说明。

## 功能

- **登记**：发现站点、发现时间、物品特征、暂存位置、保管期；同一特征在保管时效内重复登记时，只补一条发现记录，不新开一件（特征相近时列出候选由值班人确认）。
- **认领**：核对姓名、联系电话、物品细节；两人以上说中特征即挂起争议、暂停交接，绝不放行给后到的人；争议须登记判定依据才能解除。
- **交接班**：交接后在管物品的保管责任随记录移交，生成交接台账。
- **归档**：超过保管期或确认无人认领时，必须登记处置人和去向才能归档；已归档记录的更正保留原值与原因。

## 分层（资料 / 判断 / 本机保存 / 页面分开）

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `src/lostfound/types.ts`、`constants.ts` | 数据模型与基础常量 |
| 判断 | `src/lostfound/rules.ts`、`text.ts` | 查重、认领核对、争议、归档、更正等业务规则（纯函数） |
| 本机保存 | `src/lostfound/storage.ts`、`seed.ts` | localStorage 读写与演示数据 |
| 编排 | `src/lostfound/store.ts` | Pinia 状态，调用规则并持久化 |
| 页面 | `src/lostfound/components/*.vue` | 登记、台账、认领核对、处置归档、交接班界面 |

数据默认保存在浏览器 localStorage（键 `dfwlfront-7-lostfound`），页面右上角可一键重置演示数据。
